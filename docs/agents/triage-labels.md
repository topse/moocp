# Triage-Labels

`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix` (1:1-Vokabular wie in den Schwesterprojekten). Erledigte Issues werden nach Rückfrage mit `gh issue close <nr> --comment "..."` geschlossen.

Plattform: `os:windows`, `os:macos`, `os:linux`, `os:all`, `os:unclear`. Bei `os:unclear` zusätzlich `needs-info`, bis jemand das Problem auf einem anderen System nachgestellt hat; wer es geprüft hat, hat für sein System das letzte Wort. Das Issue-Formular fragt getrennt nach bestätigten und vermuteten Systemen. Alle Labels, Issues und Pull Requests sind englisch; die Zusammenarbeit steht in [CONTRIBUTING.md](../../CONTRIBUTING.md).
