# E10 SchuCu-Tabelle nur nach den Vorlagen

Status: gilt. Die Regeln dazu stehen im Index der [CLAUDE.md](../../CLAUDE.md).

## Entscheidung

Die SchuCu-Tabelle entsteht nur nach den Vorlagen (Berufsschule als Regel, Berufliches Gymnasium als Ausnahme; beide im Skill `lernsituation`). Die Vorlage wird erfragt, Fachbezüge (Lehrplan, Kompetenzbereiche) liefert die Lehrkraft, nichts wird erfunden.
