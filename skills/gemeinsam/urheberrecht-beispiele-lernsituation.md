So sieht die Angabe von Wikimedia Commons auf einem Blatt aus, druckfest
gemacht — das Bild liegt in `dateien/` des Blatts, die Bildunterschrift trägt
die Angabe:

```html
<p><a href="https://commons.wikimedia.org/wiki/File:Kontakt.svg"><img src="@@PLUGINFILE@@/Kontakt.svg" alt="Schaltzeichen eines Schließkontakts" class="img-fluid"></a></p>
<p><em>Abb. 1: Schaltzeichen eines Schließkontakts.</em> By <a href="https://commons.wikimedia.org/wiki/User:Mik81">Mik81</a>
– Own work, Public Domain,
<a href="https://commons.wikimedia.org/w/index.php?curid=3381153">https://commons.wikimedia.org/w/index.php?curid=3381153</a></p>
```

Wo keine Vorgabe vorliegt, gilt die Vier-Angaben-Form, ebenfalls druckfest:

```html
<p><em>Abb. 2: „Messschieber" von Erika Mustermann, CC BY-SA 4.0
(<a href="https://creativecommons.org/licenses/by-sa/4.0/deed.de">https://creativecommons.org/licenses/by-sa/4.0/deed.de</a>), Quelle:
<a href="https://commons.wikimedia.org/wiki/File:Messschieber.example.png">https://commons.wikimedia.org/wiki/File:Messschieber.example.png</a>, zugeschnitten.</em></p>
```

Alle fremden Inhalte einer Lernsituation stehen zusätzlich am Ende der
Handreichung im Abschnitt „Quellen und fremde Inhalte" (Vorlage in
`references/vorlagen.md`), damit die Lehrkraft auf einen Blick sieht, was sie
verteilt.
