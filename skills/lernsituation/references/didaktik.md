# Didaktik: die Regeln, nach denen eine Lernsituation gebaut wird

Das ist die lange Fassung dessen, was in `SKILL.md` unter „Was eine
Lernsituation ausmacht" steht. Hier hinein gehört alles, was man beim Füllen
der Vorlagen wissen muss — nicht mehr.

## Grundlegende Anforderungen nach SchuCu-BBS

Die Leitlinie „Schulisches Curriculum Berufsbildende Schulen" (SchuCu-BBS)
des Landes legt fest, was jede Lernsituation erfüllt — in allen
Bildungsgängen, auch im Beruflichen Gymnasium und in den allgemeinbildenden
Fächern. Die Anforderungen müssen **aus der Beschreibung erkennbar und
ausgewiesen** sein; das leistet die SchuCu-Tabelle. Die Quelle ist der
Kopflink der Tabelle („Grundlegende Anforderungen an Lernsituationen", Stand
09/2018). Was daraus für diesen Skill folgt:

- **Begriffe.** „Lernsituation" ersetzt Unterrichtseinheit, -sequenz und
  Makrosequenz; „Handlungssituation" ersetzt Ausgangssituation,
  Einstiegsszenario und Anforderungssituation. Die alten Wörter benutzt du
  nicht.
- **Titel:** kurz, prägnant, er beschreibt die Handlung — in der Regel
  Substantiv und Verb.
- **Handlungssituation:** ist der Kern und trägt den ganzen Lern- und
  Arbeitsprozess; sie **benennt den Rahmen** (Modellunternehmen, Einrichtung,
  technisches System — außerhalb des Berufsbezugs Fall, Szenario, reale
  Situation), greift die Erfahrungen der Lernenden auf und berücksichtigt
  soziale Prozesse. Im berufsbezogenen Unterricht ist sie für die
  Berufsausübung bedeutsam, im berufsübergreifenden für die Lebenswelt der
  Lernenden; im Beruflichen Gymnasium darf sie die Studienorientierung
  einbeziehen. Die Problemstellung ist komplex, exemplarisch und lässt
  verschiedene, möglichst offene Lösungswege zu.
- **Handlungskompetenz** nach DQR in zwei Dimensionen: **Fachkompetenz**
  (Wissen, Fertigkeiten) und **personale Kompetenz** (Sozialkompetenz,
  Selbstständigkeit). Kommunikations-, Methoden-, Lern- und Medienkompetenz
  stecken darin und werden nicht eigens aufgeführt. Im Beruflichen Gymnasium
  werden die Kompetenzen des Kerncurriculums auf Handlungskompetenz
  ausgerichtet.
- **Inhalte** ergeben sich aus den Kompetenzen und dem Ordnungsmittel und
  werden auf Aktualität, Komplexität, Bearbeitungstiefe und regionale
  Besonderheiten geprüft.
- **Phasen:** Informieren *bzw. Analysieren*, Planen, Entscheiden,
  Durchführen, Kontrollieren *bzw. Bewerten*, Reflektieren. Fachgruppen im
  berufsübergreifenden Bereich dürfen eigene fachdidaktische Abläufe
  festlegen; dann gelten die.
- **Fachsystematische Lernphasen sind erlaubt**, wenn sie den
  handlungsorientierten Prozess stützen — ein Lehrgang zum Konfigurieren
  mitten in der Lernsituation macht sie nicht zur Aufgabensammlung.
- **Handlungsergebnis:** greifbar oder nicht — Datei, Werkstück, Plakat,
  Handlungskonzept, Stellungnahme, Beratungsgespräch, Pro-und-Kontra-
  Diskussion, Reflexion.
- **Schulische Entscheidungen** müssen berücksichtigt werden:
  schulspezifische Bedingungen, Anforderungen an die Lernumgebung, Grundsätze
  der Leistungsbewertung, Lernortkooperationen, Materialien und Medien. Der
  Skill kennt sie nicht; was fehlt, steht als „vom Nutzer zu ergänzen" da.

## Die vollständige Handlung: sechs Phasen

| Nr. | Phase | Was die Lernenden tun | Typische Sozialform | Typisches Material |
|---|---|---|---|---|
| 1 | **Informieren** | Den Auftrag verstehen, fehlende Informationen beschaffen, Anforderungen klären | Einzel, dann Plenum | Handlungssituation, Infoblatt, Links |
| 2 | **Planen** | Lösungswege entwerfen, Arbeitsschritte festlegen, Aufgaben verteilen | Partner, Gruppe | Arbeitsblatt mit offener Aufgabe, Planungsraster |
| 3 | **Entscheiden** | Einen Weg wählen und **begründen** — gegenüber der Gruppe, dem „Kunden", der Lehrkraft | Gruppe, kurzes Plenum | Entscheidungsmatrix, Kriterienliste |
| 4 | **Durchführen** | Das Produkt herstellen: konfigurieren, bauen, schreiben, rechnen, präsentieren | Gruppe oder Einzel | Arbeitsblatt, Laborgeräte, Simulation |
| 5 | **Kontrollieren** | Das Ergebnis gegen die Anforderungen prüfen — fachlich, nicht nur „fertig" | Partner (Fremdkontrolle), Einzel | Prüfliste, Lösung, Testfälle |
| 6 | **Reflektieren** | Den *Weg* bewerten: Was hat funktioniert, was würden wir anders machen, was nehmen wir mit? | Plenum, Einzel schriftlich | Reflexionsfragen |

**Nicht jede Phase muss vorkommen.** Nach neuerer Auffassung ist die
vollständige Handlung ein Gerüst, kein Pflichtprogramm. Was aber gilt:

- Welche Phasen die Lernsituation enthält und **welche fehlt und warum**, steht
  in der Handreichung. „Reflektieren entfällt, weil die Lernsituation Teil
  einer Reihe ist und die Reflexion am Ende der Reihe erfolgt" ist ein Grund.
  Stillschweigend weglassen ist keiner.
- **Entscheiden** ist die Phase, die am häufigsten fehlt — und die, die eine
  Lernsituation von einer Übung unterscheidet. Gibt es nichts zu entscheiden,
  ist die Problemstellung zu eng.
- **Kontrollieren** ist nicht „die Lehrkraft schaut drüber". Die Lernenden
  prüfen selbst, gegen Kriterien, die sie kennen.
- Eine Lernsituation, die nur aus Informieren und Durchführen besteht, ist ein
  Arbeitsauftrag. Das kann gewollt sein — dann heißt es auch so.

Die Phase steht an jeder Zeile des Ablaufplans. Läuft eine Phase über mehrere
Zeilen, steht sie mehrfach.

## Die Handlungssituation

Der Rahmen, in dem alles passiert. Sie ist realistisch, wenn eine Fachkraft
sagen würde: „Ja, so kommt das rein." Kennzeichen:

- **Ein Auftraggeber** mit einem Anliegen, nicht mit einer Aufgabenstellung.
  Der Betriebsleiter sagt „Die Buchhaltung soll die Entwicklung nicht mehr
  sehen", nicht „Richten Sie zwei VLANs ein".
- **Unvollständige Information.** Etwas fehlt, das die Lernenden erfragen,
  nachschlagen oder annehmen müssen — und die Annahme begründen. Das ist die
  Phase Informieren.
- **Ein Handlungsprodukt**, das der Auftraggeber bekommt. Das ist der Maßstab
  für Kontrollieren.
- **Erfundene Namen, erkennbar erfunden** — Regeln in `SKILL.md`. Die Muster
  GmbH, nicht ein Betrieb, den es in der Nachbarstadt gibt.
- **Der Rahmen ist benannt**: welcher Betrieb, welche Einrichtung, welcher
  Fall. Ohne Rahmen ist es eine Aufgabe mit Vorgeschichte.
- **Umfang auf drei bis acht Sätze.** Länger liest niemand; kürzer trägt nicht.

Die Situation steht auf dem ersten Arbeitsblatt (oder in einer eigenen
Aktivität „Handlungssituation"), in der SchuCu-Tabelle verkürzt.

## Sozial- und Arbeitsformen

Der Wechsel ist kein Selbstzweck. Jede Form hat einen Grund, und der steht in
der Handreichung („Partnerarbeit, weil die Fremdkontrolle eine zweite Person
braucht").

| Form | Wofür sie taugt | Wofür nicht | Zeit (Faustregel) |
|---|---|---|---|
| **Einzelarbeit** | Informieren, Sichern, Reflexion schriftlich | Entscheiden — da fehlt der Widerspruch | 10–20 min |
| **Partnerarbeit** | Kontrollieren (Fremdkontrolle), erste Planung, Üben | große Produkte | 10–20 min |
| **Gruppenarbeit (3–4)** | Planen, Entscheiden, Durchführen von Produkten | Reinen Stoff erarbeiten — dann reden zwei, zwei warten | 20–45 min |
| **Think-Pair-Share** | Einstieg in eine offene Frage, jeder denkt zuerst selbst | Fakten | 3 + 5 + 7 min |
| **Gruppenpuzzle** | Mehrere Teilthemen, die alle brauchen | Ein einzelnes Thema | 2 × 20 min + Sicherung |
| **Stationenarbeit** | Üben in eigenem Tempo, Binnendifferenzierung | Neue Konzepte einführen | 45–90 min |
| **Lehrerimpuls / Kurzvortrag** | Einen Begriff setzen, ein Werkzeug zeigen | Mehr als 10 min am Stück | 5–10 min |
| **Unterrichtsgespräch** | Einstieg, Sicherung, Reflexion | Erarbeitung — spricht immer dieselben | 5–15 min |
| **Präsentation / Galeriegang** | Handlungsprodukte zeigen, Kontrollieren durch andere | Mehr als 5 Gruppen à 5 min | 3–5 min je Gruppe |
| **Rollenspiel (Kundengespräch)** | Entscheiden begründen, Personalkompetenz | Wenn die Klasse es nicht kennt | 10–15 min |

## Lernträger

Was die Lernenden in der Hand haben. Wähle, was zum Produkt passt, nicht was
gerade da ist:

| Träger | Wann |
|---|---|
| **Arbeitsblatt (Papier)** | immer als Rückfall; die Blätter müssen auch ohne Netz funktionieren |
| **Informationsblatt** | Stoff, den die Lernenden für den nächsten Schritt brauchen, kompakt — wenn es ihn nirgends passend gibt oder die vorhandene Quelle zu breit ist |
| **Lehrbuch, Tabellenbuch, Programmhilfe, Internet** | Wenn das Nötige dort schon gut steht, und wenn das Suchen selbst Ziel ist (Informieren): die Lernenden lernen, eine Quelle zu finden und zu lesen, die es auch im Betrieb gibt. Auf dem Blatt genau genannt oder als Recherche verlangt (`references/vorlagen.md`, Regel 5 unter „Jedes Blatt steht für sich") |
| **Video / Link** | Wenn etwas gezeigt werden muss, was ein Blatt nicht kann — mit ausgeschriebener Adresse und Angabe, wofür es gebraucht wird |
| **Simulation / Software** | Wenn das Produkt darin entsteht (Netzsimulation, CAD, Tabellenkalkulation) — Version und Voraussetzung in der Handreichung unter „Lernumgebung" |
| **Laborgerät / Werkstück** | Wenn es real geht; Sicherheitshinweis in der Handreichung |
| **Moodle** | Abgabe des Produkts, Test, die Blätter als Textseiten — die Zuordnung steht in der Brücke |

## Binnendifferenzierung: Zusatz, nicht Fassungen

Drei vollständige Fassungen desselben Blatts sind dreifacher Pflegeaufwand und
signalisieren den Lernenden, in welcher Schublade sie sitzen. Stattdessen:

- **Arbeitsblatt** für alle. Wer es schafft, hat das Lernziel erreicht.
- **Vertiefung** (`-vertiefung`): führt weiter — ein Transfer, eine Störung, eine Erweiterung des Auftrags. Für die, die früher fertig sind. AFB III.
- **Hilfe** (`-hilfe`): stützt — ein Zwischenschritt vorgegeben, eine Tabelle vorstrukturiert, ein Beispiel mehr. Für die, die festhängen. Nicht weniger Aufgabe, sondern mehr Geländer.

Die Namen sagen, was ein Blatt tut, nicht, für wen es ist: Eine Hilfe nimmt, wer festhängt, eine Vertiefung, wer weiter will. Namen wie „Basis" und „Plus" sortieren dagegen in Schwächere und Stärkere, und „Basis" liest man obendrein als das Grundlegende für alle.

Jedes Zusatzblatt hat eine eigene Lösung und steht im Ablaufplan mit seinem
Einsatz („ab min 25 für Gruppen, die fertig sind").

## Anforderungsbereiche in Aufgaben

Jede Aufgabe trägt ihren AFB — auf dem Blatt in Klammern, in der Handreichung
in der Aufgabenübersicht. Die Operatoren helfen beim Formulieren:

| AFB | | Operatoren |
|---|---|---|
| **I** | Wiedergeben | nennen, beschreiben, wiedergeben, zuordnen, aufzählen |
| **II** | Anwenden | berechnen, erklären, anwenden, planen, erstellen, vergleichen, darstellen |
| **III** | Weiterdenken | begründen, bewerten, beurteilen, entwickeln, entscheiden, prüfen, optimieren |

Eine Lernsituation lebt von II und III — die Phasen Planen, Entscheiden und
Reflektieren *sind* AFB III. Ein Blatt, das nur aus I besteht, ist ein
Informationsblatt mit Fragen. Richtwert über alle Aufgaben: etwa 30 % I, 40 %
II, 30 % III — nach Zeit, nicht nach Anzahl; die Lehrkraft entscheidet.

## Zeit

Eine Unterrichtsstunde (UStd) hat **45 Minuten**. Der Zeitrichtwert wird in
UStd genannt und im Ablaufplan in Minuten geplant.

Faustregeln, an denen sich die Schätzung messen lässt:

| Baustein | Minuten |
|---|---|
| Einstieg mit Handlungssituation, Auftrag klären | 10–15 |
| Informationsblatt lesen und Fragen dazu | 10–15 je Blatt |
| Aufgabe in Einzelarbeit (AFB I–II) | 5–15 |
| Aufgabe in Partnerarbeit | 10–20 |
| Planungsphase in der Gruppe | 20–30 |
| Durchführung eines Produkts | 30–90 |
| Präsentation | 3–5 je Gruppe + 5 Nachfragen |
| Kontrolle gegen Prüfliste | 10–15 |
| Reflexion | 10–15 |
| **Puffer** | 10 % der Gesamtzeit, als eigene Zeile |

**Plausibilitätsprüfung**, bevor die Ausarbeitung übergeben wird:

1. Summe der Zeilen im Ablaufplan = Zeitrichtwert in Minuten (± eine
   Pufferzeile). Das Skript rechnet nach.
2. Jede Aufgabenzeit auf dem Blatt passt zur Zeile im Ablaufplan.
3. Keine Gruppenarbeit unter 15 Minuten, keine Präsentationsrunde ohne
   Nachfragezeit, keine Reflexion in 5 Minuten.
4. Wenn es knapp ist: **streichen, nicht stauchen.** Eine Aufgabe weniger ist
   besser als alle zu kurz.

## Leistungsfeststellung und -bewertung

Steht ausführlich in der Handreichung (Abschnitt „Leistungsfeststellung und
-bewertung"), kurz in der SchuCu-Tabelle, und wird konkret:

- **Was wird bewertet?** Das Handlungsprodukt, die Präsentation, ein Test, das
  Arbeitsverhalten — und in welcher Gewichtung fachlich zu personal.
- **Nach welchen Kriterien?** Die Lernenden kennen sie vorher; sie stehen als
  Prüfliste auf einem Blatt, das auch zum Kontrollieren dient.
- **Wann?** Am Ende, oder prozessbegleitend (Planungsraster, Entscheidungs-
  begründung).
- Ein **Test** dazu ist Sache des Skills `moodle-fragen`; die AFB-Angaben an
  den Aufgaben sind seine Vorarbeit.

## Bestehendes einordnen

Beim Beurteilen eines vorhandenen Abschnitts fällt das Ergebnis in eine von
vier Schubladen. Die Begriffe sind so gemeint:

| Einordnung | Kennzeichen | Was daraus werden kann |
|---|---|---|
| **Lernsituation** | Situation, Problem, Entscheidung, Produkt, mehrere Phasen | Feinschliff (Soll/Kann-Befunde) |
| **Arbeitsauftrag** | ein Auftrag mit klarem Ziel, aber ein Weg, keine Entscheidung; oft nur Informieren und Durchführen | eine Entscheidung und ein Produkt dazu — der kleine Weg |
| **Aufgabensammlung** | Aufgaben in Lehrbuchreihenfolge, jede mit genau einer Lösung, keine Situation davor, kein Produkt danach, Inhalte nach Lehrplan geordnet | Aufgaben als Übungs- und Kontrollmaterial in eine Situation einbetten — der mittlere Weg |
| **Materialsammlung** | Texte, Links, Dateien ohne Aufgaben und ohne Auftrag | Material wird zu Informationsblättern einer neuen Lernsituation — Neubau |

Woran man eine **Aufgabensammlung** erkennt, konkret:

- Die erste Aktivität ist eine Aufgabe, keine Situation. „Berechne…", „Nenne…"
  ohne ein Davor.
- Die Reihenfolge ist die des Lehrbuchs oder des Lehrplans, nicht die einer
  Handlung.
- Jede Aufgabe hat genau eine richtige Lösung; nichts ist zu entscheiden, zu
  begründen oder zu wählen.
- Es gibt kein Ergebnis, das am Ende jemandem gezeigt wird.
- Zeiten, Sozialformen, Phasen fehlen; alles ist Einzelarbeit ohne Takt.
- Information und Aufgabe stehen auf derselben Seite.

Woran man einen **Arbeitsauftrag** erkennt: Es gibt ein Ziel („Richte zwei
VLANs ein") und einen Weg dorthin, aber der Weg ist vorgegeben, und nichts
zwingt zu einer Wahl. Das ist oft gewollt und nicht falsch — es ist nur keine
Lernsituation.

Jede Einordnung braucht einen **Beleg**: ein Zitat, eine Aktivität mit Namen,
eine Stelle. „Wirkt wie eine Aufgabensammlung" ist kein Befund.

Eine **fachsystematische Phase** in einem sonst handlungsorientierten
Abschnitt — ein Lehrgang, eine Übungsreihe — ist kein Befund gegen die
Lernsituation. Die Leitlinie erlaubt sie ausdrücklich, solange sie den
Handlungsprozess stützt und nicht ersetzt.

## Die Checkliste

Sie steht am Ende der Handreichung, ausgefüllt — **jede Antwort mit einem
Halbsatz Begründung**, ein bloßes „Ja" ist keine Prüfung. Ein „Nein" ist
erlaubt, wenn der Grund dasteht.

| Frage | Ja/Nein | Woran man es sieht |
|---|---|---|
| Gibt es eine realistische Handlungssituation? | | |
| Gibt es eine konkrete Problemstellung? | | |
| Gibt es mehrere Lösungswege? | | |
| Müssen Entscheidungen getroffen werden? | | |
| Werden alle Phasen der vollständigen Handlung durchlaufen? | | *Nein ist zulässig — welche fehlt, warum?* |
| Entsteht ein Handlungsergebnis? | | |
| Werden Fach- und Personalkompetenzen gefördert? | | |
| Arbeiten die Lernenden selbstständig? | | |
| Gibt es kooperative Lernanteile? | | |
| Gibt es eine Reflexionsphase? | | |
| Dienen die Inhalte der Handlung? | | |
| Benennt die Handlungssituation den Rahmen? | | |
| Sind schulische Entscheidungen berücksichtigt? | | *Lernumgebung, Bewertungsgrundsätze, Lernortkooperation — was der Skill nicht weiß, steht als „vom Nutzer zu ergänzen" da* |

Drei „Nein" ohne guten Grund heißen: Das ist keine Lernsituation. Dann zurück
zu den Vorschlägen, nicht weiter mit der Ausarbeitung.
